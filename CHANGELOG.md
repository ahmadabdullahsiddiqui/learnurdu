# Changelog

All notable changes to **Ustad — The Urdu Teacher**. Tagged versions are restore
points on GitHub; the live site always tracks `main`.

## v1.5.12 — 2026-09-16

- ✍️ **Writing practice (Write tab)** — trace letters and words on a canvas with a
  fade‑in nastaliq guide, plus a kid‑friendly **Check** button that celebrates a
  genuine attempt (no strict grading).
- 🔊 **Voice** — only real Urdu voices are offered (no Hindi); optional
  *“use my device’s voice”* mode; the bundled offline audio is the silent default.
- 🔔 **Auto‑update** — an open app checks for new versions (30 s poll +
  `controllerchange`) and shows a dismissible *“update available”* bar instead of
  a surprise reload.
- 🗄️ Storage key renamed to `urdu.ahmadabdullah`.
- 🧩 Extension version now auto‑syncs to `APP_VERSION` at build time.
- 📄 README refreshed; this changelog added.

## v1.4.1 — 2026

- 💬 More **Phrases** — full everyday sentences across new phrase sets.

## v1.4.0 — 2026

- 📚 Content expansion — additional vocabulary topics and phrase sets.
- 🎮 **Memory Match** game.
- 🇬🇧🇩🇪 Full **English / German** UI switch (labels, blurbs, grammar notes and
  word meanings).

## v1.2.1 — 2026

- 🔒 Security hardening — externalised inline JS, stricter CSP, tighter
  service‑worker caching.

## v1.2.0 — 2026

- 🔢 **Numbers 1–100** section and more vocabulary.
- 🎉 Quiz celebration when you ace it; kid‑friendly colourful theme.

## v1.1.0 — 2026

- 🔊 Bundled **offline pronunciation audio** (works on iPhone/iPad, which have no
  Urdu voice).
- 🧩 Installable **Manifest V3 browser extension**; bundled offline fonts.

## v1.0.0 — 2026

- 🚀 First release — vocabulary, phrases, nastaliq script and grammar, with
  spaced‑repetition flashcards and quizzes, as an offline PWA.
